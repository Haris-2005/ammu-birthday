FOR AMMU - BIRTHDAY WEBSITE
============================

This is a free HTML/CSS/JS website designed for GitHub Pages.

FILES
-----
index.html  -> main page
style.css   -> design and animations
data.js     -> all dates/memories
script.js   -> interactions and photo modal
images/     -> create one folder per date and put photos inside

PHOTO SETUP
-----------
Create folders such as:
images/2025-03-15/
images/2025-06-08/
images/2025-07-19/
...

Then in data.js change a memory's images from [] to something like:
images: ['images/2025-03-15/1.jpg', 'images/2025-03-15/2.jpg']

The website will automatically show those photos in the cute memory-opening modal.

GITHUB PAGES
------------
1. Create a GitHub repository.
2. Upload every file/folder from this project.
3. Open Settings -> Pages.
4. Select Deploy from branch -> main -> /(root).
5. Save and wait for the Pages URL.

No paid hosting is required.
